## 一、后端自动化测试（P0，原评级最大风险）

新增 6 个单元测试类，共 **36 个用例**，覆盖核心链路：

| 测试类                   | 覆盖点                                                    | 用例数 |
| --------------------- | ------------------------------------------------------ | --- |
| `CryptoServiceTest`   | SM4/AES 加解密往返、SM3/MD5/SHA256 摘要、**SM2 签名验签**（篡改数据验签失败） | 7   |
| `DesensitizeUtilTest` | 手机/身份证/银行卡/邮箱/Token 密钥脱敏                               | 6   |
| `CryptoKeyUtilTest`   | AES 密钥 Base64 编解码                                      | 4   |
| `IpUtilTest`          | CIDR 网段匹配、单 IP 匹配、边界                                   | 5   |
| `AppAuthHandlerTest`  | 应用认证主流程（Mockito 模拟依赖）                                  | 9   |
| `GatewayContextTest`  | X-Forwarded-For 信任策略、认证头解析                             | 5   |

**测试驱动修复了 2 个真实 Bug：**

1. **SM2 签名功能完全失效**
   - 现象：`CryptoServiceImpl.sm2Sign` 调用 Hutool `signHex(data)` 时直接传明文，而 `signHex` 入参应为十六进制数据 → 任何签名调用都会抛异常。
   - 修复：签名/验签前用 `HexUtil.encodeHexStr(data.getBytes(UTF_8))` 转 Hex；`generateSM2KeyPair` 改为返回 Hex 格式密钥（私钥 D 值、公钥未压缩点），与 SM2 构造函数一致。
2. **敏感信息脱敏缺陷**
   - 现象：邮箱脱敏后 `@` 被吃掉（`zha***example.com` 不再是合法邮箱）；密码含 `@`/`#` 等特殊字符时整个值未被脱敏。
   - 修复：邮箱替换串保留 `@`（`$1***@$2`）；Token 值字符类由 `[A-Za-z0-9\-_.]` 扩展为分隔符之前的任意字符 `[^\s"'`,}]]+\`。

## 三、日志导出 CSV + 操作审计落库（P1）

- **调用日志导出**：`CallLogController` 新增 `GET /log/export`，复用分页查询拉取全量匹配记录，手写 CSV（含中文表头 + UTF-8 BOM 供 Excel 识别），字段含应用/接口/方法/时间/状态码/耗时/IP/限流/拦截等。前端 `exportCallLog` 以 `blob` 接收触发下载。
- **操作审计 AOP**：新增 `aspect/OperationLogAspect.java`（`@Around` 拦截 `controller` 包写操作），自动从请求路径首段推导模块（APP/INTERFACE/PERMISSION/SYSTEM/SECURITY/ENCRYPTION/GROUP）、从 HTTP 方法推导操作类型（CREATE/UPDATE/DELETE），操作人取自 JWT 拦截器写入的 `X-USER-ID`/`X-USERNAME`，落 `sys_operation_log`。排除网关转发（`/gateway`）与登录登出（`/auth`）；审计写入失败仅告警、不阻断业务。
