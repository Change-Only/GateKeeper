# GateKeeper UI 设计方案 V2 — 「守门人」视觉语言升级

> 版本：V2.0 | 日期：2026-08-29 | 设计师：UI Designer
> 交付范围：设计系统规范 + 全部 10 个页面高保真原型（登录 / 统计仪表盘 / 应用管理 / 接口管理 / 权限管理 / 加解密管理 / 调用日志 / 安全防护 / 系统设置 / 数据大屏）
> 实现约束：优先贴合 Element UI 组件体系，落地成本可控

---

## 一、设计背景与理念

### 1.1 目标用户与场景

| 用户 | 核心场景 | 设计诉求 |
|------|---------|---------|
| 系统管理员 | 每天高频：应用注册、接口配置、权限分配 | 效率优先：表格密度、批量操作、搜索筛选顺手 |
| 安全运维 | 每天高频：日志排查、封禁处置、事件跟进 | 状态可辨：异常一眼可见，操作路径短 |
| 管理层 | 低频：大屏看板、定期汇报 | 态势直观：关键指标与趋势突出 |
| 应用开发者 | 低频：获取凭证、查接入文档 | 引导清晰：登录后能找到帮助 |

### 1.2 品牌意象 — 「守门人 GateKeeper」

产品本质是"守门人"：所有 API 调用的唯一入口、规则的执行者。视觉语言围绕三个关键词：

- **防线**：细直线、精确对齐、克制的分隔——视觉上传递"规则清晰、边界明确"
- **可靠**：深海军蓝 + 信号蓝的稳重配色、均衡的比例——传递"值得托付"
- **通透**：高信息密度但层次分明，状态色语义一致——异常一眼可见

### 1.3 与 V1 的差异（升级点）

| 维度 | V1 现状 | V2 升级 |
|------|---------|---------|
| 侧栏 | 纯色 #0f2744 | 深海军蓝渐变 + 激活态左侧 3px 指示条 + 图标描边态 |
| 卡片 | 直角 | 10px 圆角 + 双层柔和阴影，hover 微抬升 |
| KPI | 纯数字 | 图标徽章 + 环比趋势箭头 + 迷你走势线 |
| 表格 | 默认样式 | 表头浅灰底、行 hover 高亮、状态标签统一体系、操作列分组 |
| 按钮 | 单色 | 主按钮渐变微光 + 明确的 primary/default/danger 三级 |
| 大屏 | 深色纯面板 | 深空蓝底 + 面板玻璃层次 + 青色数据高亮 + 发光边框 |

## 二、设计 Token 系统

### 2.1 色彩系统（管理后台 · 浅色）

| Token | 色值 | 用途 |
|-------|------|------|
| `--brand-600` | `#2563eb` | 品牌主色：主按钮、链接、选中态 |
| `--brand-700` | `#1d4ed8` | 主色 hover/active |
| `--brand-100` | `#eaf1ff` | 主色浅底：选中行、信息标签底 |
| `--navy-900` | `#0b1c33` | 侧栏底色（深海军蓝） |
| `--navy-800` | `#10264a` | 侧栏 hover、下拉面板 |
| `--bg-page` | `#f4f6fa` | 页面背景（蓝调浅灰） |
| `--surface` | `#ffffff` | 卡片/面板表面 |
| `--border` | `#e3e8f2` | 常规边框 |
| `--text-strong` | `#17233d` | 主文字 |
| `--text-secondary` | `#5c6b8a` | 次要文字 |
| `--text-muted` | `#9aa7bf` | 占位/禁用文字 |

### 2.2 语义色（状态标签/按钮，与安全语义一致）

| 语义 | 前景 | 背景 | 适用 |
|------|------|------|------|
| success | `#0e7a5f` | `#e2f6ee` | 启用、200、生效中、封禁已解封 |
| warning | `#96611a` | `#fdf1dd` | 已过期、429 限流、待轮换、到期提醒 |
| danger | `#c03337` | `#fdeaea` | 停用、403 拦截、封禁中、自动封禁 |
| info | `#2053c4` | `#eaf1ff` | SM4/AES、方法标签、分组、正常 |
| neutral | `#5c6b8a` | `#eef1f7` | 无加密、次要信息 |

### 2.3 数据大屏（深色）专用

| Token | 色值 | 用途 |
|-------|------|------|
| `--screen-bg` | `#070d1a` | 大屏背景 |
| `--screen-panel` | `rgba(15,27,54,.72)` | 面板（玻璃层次） |
| `--screen-line` | `rgba(86,150,255,.22)` | 面板发光边框 |
| `--cyan` | `#35c8f0` | 数据主高亮（趋势线、排行） |
| `--blue` | `#4d7cfe` | 次要数据（柱状） |
| `--green` | `#2fd49b` | 成功率/正常 |
| `--orange` | `#f5a524` | 告警 |
| `--red` | `#ff5f6e` | 异常/封禁 |

### 2.4 字体与排版

- 字体族：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`
- 数字：全局 `font-variant-numeric: tabular-nums`（数字等宽对齐，表格/指标更整齐）
- 字号阶梯：12（辅助/标签）/ 13（正文/表格）/ 14（强调正文）/ 16（页面标题）/ 20（KPI 数值·后台）/ 28（KPI 数值·大屏）
- 字重：400 正文 / 500 强调 / 600 标题
- 行高：正文 1.6，表格 1.5

### 2.5 间距、圆角、阴影

- 间距基数 4px：4 / 8 / 12 / 16 / 20 / 24；页面内容区边距 20px；卡片内边距 20px
- 圆角：卡片 10px、按钮/输入 8px、标签 6px、大屏面板 10px
- 阴影（卡片）：`0 1px 2px rgba(13,26,52,.04), 0 4px 12px rgba(13,26,52,.06)`
- 阴影（悬浮）：`0 6px 20px rgba(13,26,52,.10)`
- 动效：统一 `150ms ease-out`；hover 仅微抬升 1px（不夸张）

## 三、组件规范（Element UI 落地映射）

### 3.1 布局框架
- **侧栏**（200px，深海军蓝）：Logo 区 56px；菜单项 40px 高、13px 字、图标 16px；激活态 = 左侧 3px 品牌蓝指示条 + `--navy-800` 底 + 白字；分组菜单可折叠
- **顶栏**（56px，白底）：左面包屑（"工作台 / 统计仪表盘"）；右侧搜索框（280px，⌘K 提示）、通知铃铛（红点）、用户头像下拉
- **内容区**：`--bg-page` 底，最大宽度不设限（管理后台场景）

### 3.2 按钮
| 类型 | 规格 |
|------|------|
| primary | 品牌蓝底白字，hover 加深 #1d4ed8；用作页面唯一主操作 |
| default | 白底 + `--border` 边框；用于次要操作（重置、取消） |
| danger | 浅红底 `#fdeaea` + `#c03337` 字（封禁、删除） |
| text | 蓝色文字按钮，用于表格操作列 |

### 3.3 表格（管理后台核心组件）
- 表头：`#f7f9fd` 浅底、12px、`--text-secondary`、字重 500
- 行高 52px；行 hover `#f7faff`；操作列右对齐，文字按钮间距 12px
- 状态用语义标签；AppKey 等凭证用等宽字体 + 复制图标
- 分页右对齐，`layout="total, sizes, prev, pager, next"`

### 3.4 输入与筛选
- 输入框：白底、`--border` 边框、8px 圆角、focus 时品牌蓝边框 + 3px 浅蓝光晕
- 筛选区：标签(12px 次要色) + 控件横排，右侧"查询(primary)/重置(default)"

### 3.5 KPI 卡片（仪表盘）
- 结构：左 40px 圆角图标徽章（浅色底 + 品牌色图标）｜ 中 标题(12px 次要色) + 数值(20px 600) ｜ 右 环比箭头（升绿/降红）+ 迷你走势线
- 卡片 hover 微抬升 + 阴影加深

### 3.6 弹窗
- 标题 16px/600；表单两列网格 `1fr 1fr`；底部右对齐（取消 default / 确定 primary）
- 危险操作（重置密钥、解封确认）用 danger 按钮

## 四、页面设计方案

### 4.1 登录页
- **布局**：左右分割 55% / 45%
- **左·品牌区**：深海军蓝渐变底 + 细网格纹理 + 居中品牌内容——盾牌 Logo、产品名 GateKeeper、价值主张一句话（"统一入口 · 权限可控 · 加密传输"）、三条安全特性清单（图标 + 短句）、底部版权
- **右·登录区**：白底居中 380px 卡片——"欢迎回来"、账号/密码（Element 输入框 + 图标前缀）、记住我 + 忘记密码、全宽主按钮"登 录"、底部"接入文档 →"链接
- **交互**：密码可见切换；登录失败时输入框红框 + 顶部错误提示条；连续失败 5 次锁定提示（与 PRD 一致）

### 4.2 统计仪表盘
- **结构**（自上而下）：
  1. 顶栏（面包屑 + 搜索 + 通知 + 用户）
  2. KPI 行 ×4：今日总调用 / 调用成功率 / 平均耗时 / 异常调用——各带图标徽章、环比、迷你走势线
  3. 主区两列：左 2/3 24h 调用趋势折线图（含凌晨低谷阴影区、异常时段 23:00-06:00 标记）；右 1/3 错误分布环形图（4xx/5xx/限流/其他 + 图例）
  4. 次区三列：接口热度 TOP8（横向条形）/ 应用调用排行 TOP8 / 耗时分布（P50/P90/P99 三档对比）
- **交互**：图表卡片右上角时间范围切换（今日/近7天/近30天）；hover 数据点显示 tooltip

### 4.3 应用管理
- **工具栏**：搜索框（应用名称/AppKey）+ 状态下拉筛选 + 右侧"＋ 创建应用"主按钮
- **表格列**：应用名称（+AppKey 等宽字体复制）｜状态标签｜IP 白名单（条数）｜QPS / 日调用量｜到期时间（7 天内到期显示橙色"即将到期"）｜操作（编辑 / 权限 / 加密 / 停用 / 删除）
- **交互**：行 hover 高亮；停用需二次确认；创建应用走弹窗表单（名称/描述/到期时间/IP 白名单动态行/限流三参数）
- **空状态**：无数据时插图 + "暂无应用，点击右上角创建第一个应用"引导

### 4.4 数据大屏（1920×1080）
- **顶部标题栏**：居中大标题"GateKeeper 安全态势监控中心" + 两侧装饰线 + 右侧实时时钟
- **KPI 行 ×4**：实时 QPS / 今日总调用 / 调用成功率 / 活跃应用数（大字 + 环比 + 青色高亮）
- **中部**：左 2/3 24h 调用趋势大折线（青色渐变面积 + 告警阈值虚线）；右 1/3 安全态势（异常调用/封禁 IP/限流次数/连续失败 四项指标条）
- **底部三列**：应用访问量 TOP10 横向柱状｜接口热度 TOP10｜最近异常事件滚动列表（时间 + 事件 + 状态标签）
- **刷新**：KPI 10s、图表 30s；右上角显示"上次刷新时间"

### 4.5 接口管理
- **布局**：左侧 200px 分组树卡片 + 右侧接口列表（`grid-template-columns:200px 1fr`）
- **分组树**：根节点"全部接口(42)"；二级分组（订单域/用户域/支付域/数据域/系统域）带数量徽章与展开箭头；三级子分组缩进；激活态 = 品牌蓝浅底 + 蓝字
- **接口列表**：工具栏（名称/路径搜索 + 方法筛选 + 状态筛选 + 批量导入 + 新建接口）；表格列：接口名称｜路径+方法（方法用彩色小标签 POST=蓝 GET=绿 PUT=橙 DELETE=红）｜分组｜入参加密｜返参加密（SM4/AES/无 标签）｜超时(ms)｜状态｜操作
- **交互**：分组树点击过滤列表；行操作"编辑/加密/删除"

### 4.6 权限管理
- **核心**：应用 × 接口授权矩阵（行=应用，列=接口）
- **单元格**：18px 圆角方块——已授权=品牌蓝底+白色对勾，未授权=白底边框；点击即切换授权，hover 显示蓝色描边提示可点
- **工具栏**：应用/分组筛选 + "按分组批量授权" + "保存授权变更"
- **底部图例**：已授权（点击取消）/ 未授权（点击授权）+ 右侧提示"授权变更即时生效"

### 4.7 加解密管理
- **顶部概览**：三张 KPI 卡——应用级配置数 / 接口级配置数 / 待轮换密钥数（橙色强调）
- **配置列表**：配置对象（应用名或接口路径）｜维度（应用级/接口级标签）｜算法（SM2/SM4/AES 标签）｜模式｜密钥（等宽字体脱敏显示 + 复制）｜版本号 vN｜状态（生效中/待轮换/已失效）｜操作（轮换/编辑）
- **关键交互**：轮换需二次确认并提示"旧密钥保留 30 天过渡期"；底部说明"密钥加密存储"

### 4.8 调用日志
- **筛选栏**（白卡横排）：时间范围（双日期输入）｜应用下拉｜接口路径｜状态码｜调用 IP + 查询/重置 + 右侧"导出 CSV"
- **日志表格**：时间(等宽)｜应用｜接口+方法标签｜状态码（200 绿/403 红/429 橙/500 红）｜耗时｜调用 IP｜加密算法｜标记（已限流/已拦截/后端异常）｜详情
- **细节**：分页右侧注明"共 N 条 · 敏感字段已自动脱敏"

### 4.9 安全防护（三 Tab）
- **Tab 1 · IP 封禁管理**：封禁列表（IP｜关联应用或"全局"｜类型 手动/自动｜原因｜开始时间｜剩余时长｜状态｜解封）；右上角危险按钮"手动封禁"弹出弹窗（两列表单：IP / 关联应用 / 封禁时长 / 原因，取消 + 红色确认）
- **Tab 2 · 安全事件**：事件类型标签（连续鉴权失败/权限越界/异常入参/高频调用）+ 处理状态（待处理/已处理/已忽略）+ 处置操作
- **Tab 3 · 检测规则配置**：5 条规则（高频/异常时段/连续失败/异常入参/权限越界），展示检测条件、触发动作、阈值参数、启用开关

### 4.10 系统设置
- **左侧设置导航**：系统配置 / 用户管理 / 角色管理 / 操作审计（卡片式小导航，激活态浅蓝底）
- **系统配置**：网关参数表单（默认超时、日志保留天数、异常时段起止，两列网格）+ 保存按钮
- **用户管理**：表格（用户名+描述｜角色标签｜状态（正常/已锁定）｜最近登录｜登录 IP｜编辑/停用/解锁）

## 五、状态与边界设计

| 状态 | 方案 |
|------|------|
| Loading | 骨架屏（表格行灰条闪烁）+ 图表区域加载占位 |
| Empty | 语义插图 + 一句话引导 + 行动按钮（如"创建应用"） |
| Error | 页面内错误卡（重试按钮），不整页跳转 |
| 危险操作 | 二次确认弹窗，红色主按钮，说明不可逆后果（如密钥重置） |
| 到期提醒 | 到期前 7 天表格内橙色"即将到期"标签 + 大屏告警流 |

## 六、响应式策略

- **≥1440px**：完整布局（侧栏 200 + 内容区）
- **1024-1439px**：KPI 四列 → 两列；图表两列 → 单列堆叠；表格横向滚动
- **<1024px**：侧栏折叠为 64px 图标模式（顶栏按钮切换）
- 数据大屏固定 1920×1080，用 `transform: scale()` 等比适配任意分辨率投屏

## 七、可访问性（WCAG AA）

- 正文文字与背景对比度 ≥ 4.5:1；次要文字 ≥ 3:1（正文 13px 已达标）
- 所有交互元素有 focus 可见焦点环（品牌蓝 2px + offset 2px）
- 状态不只靠颜色表达：标签同时含文字（如"封禁中"不只红点）
- 触控目标 ≥ 32px；图标按钮有 `aria-label`

## 八、落地映射表（Element UI）

| 设计组件 | Element UI 落地 |
|---------|----------------|
| 侧栏/菜单 | `el-menu`（router 模式，自定义激活态样式） |
| KPI 卡/趋势图 | 自研轻组件 + `echarts` |
| 表格/分页/弹窗/表单 | `el-table` / `el-pagination` / `el-dialog` / `el-form` |
| 状态标签 | `el-tag` 自定义 5 色类 |
| 搜索/筛选 | `el-input` + `el-select` |
| 大屏 | 独立路由 + ECharts 深色主题 + `setInterval` 轮询 |
