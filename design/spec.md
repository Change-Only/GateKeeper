# GateKeeper UI 设计规范（design spec）

> 版本：V1.0 | 更新时间：2026-08-28 | 编写：UI 设计师
> 适用于 PC 端管理后台（浅色）与数据大屏（深色）两套视觉体系。

---

## 一、设计原则

1. **简洁专业**：企业级管理后台，信息密度高但克制，减少装饰。
2. **一致性**：所有页面共用同一套侧栏、顶栏、表格、标签、按钮组件。
3. **状态可辨**：启用/停用/过期/正常/限流/拦截等状态用统一的语义色标签区分。
4. **大屏独立**：数据大屏采用深色科技风，与后台浅色体系解耦。

## 三、字体规范

| 层级 | 字号 | 字重 |
|------|------|------|
| 页面标题 | 16px | 600 |
| 卡片/面板标题 | 13px | 600 |
| 正文/表格 | 13px | 400 |
| 辅助说明/标签 | 12px | 400 |
| 侧栏菜单 | 13px | 400（激活 500） |
| KPI 数值（后台） | 24px | 600 |
| KPI 数值（大屏） | 24px | 600 |
| Logo | 16px | 600 |

- 字体族：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`
- 数字/耗时/路径等建议用等宽或统一西文字体，便于对齐。

## 五、组件规范

### 5.1 侧栏导航
- 宽度 200px，深蓝背景 `#0f2744`，粘性定位（sticky）随滚动固定。
- 菜单项：字号 13px，圆角 6px，悬停 `rgba(255,255,255,.06)`，激活态品牌蓝底白字。
- 「数据大屏」用青色 `#22d3ee` 标识特殊入口。

### 5.2 顶栏
- 左侧面包屑（次要文字色），右侧用户头像 + 用户名。
- 头像 26px 圆形，信息蓝底。

### 5.3 按钮
- 默认：白底 + 边框 `#d1d5db`。
- 主操作：品牌蓝底白字（`btn-primary`）。
- 危险操作：`#fcebeb` 底 + `#a32d2d` 字（如「手动封禁」「确认封禁」）。

### 5.4 标签（tag）
- 圆角 4px，内边距 `2px 8px`，字号 12px。
- 语义色见 2.2 表；方法标签（POST/GET）用更小字号 11px + 内边距 `2px 6px`。

### 5.5 表格
- 表头：背景 `#fafafa`，文字次要色，字重 500。
- 行：下边框 `#e5e7eb`，末行无边框。
- 操作列用蓝色文字链接（编辑/权限/加密/删除/详情/解封/轮换）。

### 5.6 表单
- 输入框/下拉：白底、边框 `#e5e7eb`、圆角 6px、字号 13px、内边距 `8px 12px`。
- 表单网格（封禁弹窗）：两列 `grid-template-columns:1fr 1fr`，label 12px 次要色。

### 5.7 分组树（接口管理）
- 宽 180px 卡片，分组项显示名称 + 数量（`全部接口 10`）。
- 激活态：信息蓝底 `#e6f1fb` + `#185fa5` 字。

### 5.8 授权矩阵（权限管理）
- 单元格 20px 方形，已授权=信息蓝底打勾，未授权=边框空框。
- 底部附图例（已授权/未授权）。

### 5.9 登录页
- 居中卡片 360px，Logo 居中 + 副标题 + 账号/密码表单 + 全宽主色登录按钮。

---

## 六、数据大屏规范

- 全屏深色 `#0a1428`，适配 1920×1080 投屏。
- 布局：顶栏（标题+时钟）→ 4 个 KPI 卡片 → 中间三列（趋势折线 / 应用 Top5 / 接口 Top5）→ 底部三列（安全态势 / 成功率环形 / 最近异常事件）。
- 图表主色：折线 `#60a5fa`、排行 `#60a5fa` 或 `#22d3ee`、环形 `#34d399`。
- 数据刷新：KPI 每 10 秒、图表每 30 秒（轮询）。
